# 1. Ideation Phase

In this folder, all content related to the Ideation Phase of the Smart Campus Management System (SCMS) is stored.

## Included Files:
* `1.1 Brainstorming Idea.pdf`: Brainstormed ideas for digitizing campus leave, course enrollments, and helpdesk requests.
* `1.2 Problem Statement.pdf`: Detailed challenge analysis of manual university operations and proposed ServiceNow solutions.
* `1.3 Empathy Map Canvas.pdf`: User personas mapping for Students, Faculty, HODs, and System Administrators.
