# 2. Requirement Analysis

In this folder, all the content related to Requirement Analysis for the Smart Campus Management System (SCMS) is stored.

## Included Files:
* `2.1 Technology Stack.pdf`: Breakdown of ServiceNow scoped application platform tools, Studio, Flow Designer, and Script Includes.
* `2.2 Solution Requirements.pdf`: Functional and non-functional requirements for custom SCMS tables (`x_scms_*`).
* `2.3 Data Flow Diagrams and Use Case.pdf`: DFD diagrams mapping student requests through approval flows and notification engines.
